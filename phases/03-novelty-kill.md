# Phase 3 — Novelty Kill

## Purpose

Try hard to determine whether a candidate question is already answered, substantially undermined by prior work, or left with only an uninteresting residual.

Candidate death is a successful outcome.

## AI should

For each serious candidate:
- search through multiple independent literature routes when practical;
- run a separate very-recent search;
- identify the closest prior work, not merely broadly related papers;
- compare the candidate directly with what that work establishes;
- search for contrary results and known limitations;
- distinguish “exact experiment not done” from “scientific point already understood.”

Answer two separate questions:

1. Has the substantive question already been answered?
2. If not, would resolving the remaining uncertainty teach us something meaningful?

Summarize evidence before giving a recommendation.

## Human should

Read enough of the closest work to understand why it matters.

Then decide:
- CONTINUE;
- REFORMULATE;
- KILL;
- or remain BLOCKED pending evidence.

A reformulation is a new candidate, not a hidden rescue of the old one.

## Avoid

- treating keyword novelty as scientific novelty;
- trusting one retrieval system;
- letting fluent synthesis substitute for retrieval completeness;
- continuing merely because some technically distinct experiment exists.

## Exit condition

The surviving candidate has a clearly stated residual question, identified closest prior work, and a human judgment that answering the residual would still be scientifically worthwhile.
